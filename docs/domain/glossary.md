# Glossary

**Version band:** `0.2.x` · **Status:** first draft · **Last updated:** 2026-08-22

Shared vocabulary for sela's domain. English is the working language of documentation and code;
German terms are kept where they are the precise legal or technical term, per `CLAUDE.md` §5.
Each entry states the term this codebase actually uses — the identifier or label a reader will
meet in schema, code, or UI — not just a definition.

---

## Spatial units

| Term | Meaning |
|---|---|
| **Spatial unit** (`spatial_unit`) | The atomic area every criterion, outcome, and score attaches to. Abstracted over `kind` (ADR-0001) so more than one concrete unit type can coexist. |
| **Hex cell** / **grid cell** (`hex_grid`) | The `0.2.x`–`0.3.x` spatial unit: a 100 m hexagon generated by PostGIS `ST_HexagonGrid`, clipped to a pilot region boundary. Carries no cadastral meaning — see ADR-0001. |
| **Flurstück** | The German cadastral parcel — the unit a landowner or municipality recognises as "their" land, held in ALKIS (*Amtliches Liegenschaftskatasterinformationssystem*). Not the `0.2.x` spatial unit (ADR-0001); a future `spatial_unit.kind` addition. |
| **Flächennutzungsplan** (FNP) | The municipal land-use plan — the statutory document a municipality's own zoning decisions must follow. sela's outputs are advisory input to this process, never a substitute for it (`CLAUDE.md` §5). |
| **Landschaftsschutzgebiet** | A landscape protection area — a lighter statutory protection category than *Naturschutzgebiet*, still a relevant constraint or exclusion input for `develop` suitability. |
| **Naturschutzgebiet** | A nature reserve — a strict statutory protection category. Distinguished from *Landschaftsschutzgebiet* because the two carry different constraint weight (U4). |
| **Schutzgebiet** | Protection area, used as the general term when a source (e.g. BfN's dataset) covers several protection categories together. |
| **Netzverknüpfungspunkt** | Grid connection point — where a generation asset physically connects to the electricity network. Referenced in `docs/product/mvp.md` §4 as a strong real-world suitability driver; in-scope status is open (U3). |

## Scenarios

| Term | Meaning |
|---|---|
| **Scenario** (`scenario`) | One of the four always-compared futures for a spatial unit: `status_quo`, `develop`, `preserve`, `restore` (`docs/product/mvp.md` §5). Never shown in isolation (`CLAUDE.md` §4.2). |
| **Status quo** (`status_quo`) | Baseline scenario — what the land does today. The reference every other scenario is measured against; never the implied default (`docs/product/mvp.md` §5, rule 1). |
| **Develop** (`develop_pv`, `develop_agripv`, `develop_wind`) | One scenario per in-scope technology (§ below): what is gained if the unit is built on. |
| **Preserve** (`preserve`) | What is protected if the unit stays untouched — a quantified value, not a residual (`docs/product/mvp.md` §5, rule 2). |
| **Restore** (`restore`) | What improves if the unit is actively restored or renatured, with an indicative time-to-effect. |

## Technologies

| Term | Meaning |
|---|---|
| **Freiflächen-Photovoltaik** (ground-mounted solar PV) | Open-field solar installation. See `docs/product/mvp.md` §4.1 for its criteria. |
| **Agri-Photovoltaik** (agrivoltaics) | Dual-use solar that keeps agricultural production underneath or between panel rows. See `docs/product/mvp.md` §4.2. |
| **Onshore wind** | Wind turbines sited on land (as opposed to offshore). See `docs/product/mvp.md` §4.3. |
| **Bodenzahl** / **Ackerzahl** | Statutory German soil-quality indices — *Bodenzahl* for general soil quality, *Ackerzahl* its cropland-adjusted derivative. An agrivoltaics suitability input. |

## Criteria, outcomes, and evidence

| Term | Meaning |
|---|---|
| **Criterion** (`criterion_definition`, `criterion_value`) | The atomic unit of explanation: a named, sourced, weighted, directional input to a score (`docs/product/mvp.md` §8.2). No composite may hide its criteria. |
| **Outcome dimension** (`outcome.dimension`) | One of the six shared axes scenarios are compared on: energy, climate, nature capital, soil and water, land use, local benefit (`docs/product/mvp.md` §8.3). |
| **Confidence** (`confidence`) | A per-criterion and per-outcome quality/applicability signal, always visible where the value is shown, never only on an evidence screen (`docs/product/design-language.md` §8). |
| **Not yet modelled** (`status = 'not_modelled'`) | The explicit, first-class state for an outcome dimension sela cannot yet quantify for a given scenario. Never rendered as zero, never silently omitted (`docs/product/mvp.md` §8.3). |
| **Biotopwertverfahren** | An established German method for scoring habitat/biotope value. Candidate citation basis for the nature-capital outcome dimension (U2) — only used if actually adopted and cited, never approximated. |
| **Umweltverträglichkeitsprüfung** (UVP) | Statutory environmental impact assessment. sela produces pre-assessment signals only and is never a substitute for one (`docs/product/mvp.md` §3, non-goals). |

## Provenance and licensing

| Term | Meaning |
|---|---|
| **Source** (`source`) | A cited dataset: publisher, version, retrieval date, licence, and whether its derived outputs may be redistributed (`redistributable`). Every criterion traces to exactly one. |
| **Redistributable** | Whether a dataset's licence permits publishing values *derived* from it, not just the raw data itself. Tracked per source because this differs by dataset even within one publisher (U7). |
